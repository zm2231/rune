- **iOS: `Family::Named("System Font")` and `Family::SystemMono` are San Francisco and SF Mono.** iOS names the system font's families `.SF UI` and `.SF UI Mono` and keeps them in `SFUI.ttf` and `SFUIMono.ttf`, where macOS has `.SF NS`, `.SF NS Mono`, `SFNS.ttf` and `SFNSMono.ttf`; Rune looked for the macOS files, so on iOS both families loaded no file and text asking for them fell back to the next family. On Apple platforms the system font's files now come from the system itself: the file CoreText's UI font says it is in, the file of that font's italic, and SF Mono's beside them, named after the UI font's. `System Font`, `.SF NS` and `.SF UI` find the UI font's files on macOS and iOS, and `.SF NS <X>` or `.SF UI <X>` the file beside them named for `<X>` where there is one (`Mono`, `Rounded`, `Symbols`: `SFNSMono.ttf`, `SFUIMono.ttf`), as `.SF NS <X>` did on macOS; none of them is matched by name. The family a text names is still the one in the file: `System Font` on both platforms, `.SF NS` on macOS only and `.SF UI` on iOS only, so `Family::Named("System Font")` is the portable spelling, and `Family::SystemMono` picks whichever Mono family loaded. macOS loads the files it did before.
