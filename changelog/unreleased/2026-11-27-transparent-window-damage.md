- **A transparent window on Windows redraws and presents only what changed, and a window whose compositor draws its own pixels draws whole.** A window with a fully transparent clear, such as one behind an active `WindowBackdrop` or `SystemMaterial::Glass`, drew and presented every frame whole, because the quad that clears a changed rectangle blends and can't erase the pixels under it. Its changed rectangles are now zeroed by a copy before they are redrawn, so a spinner on a glass window redraws and presents only around the spinner; a clear that is translucent but not fully transparent still draws whole. The web's loop-only frames take the same path on a transparent canvas. A window whose `Compositor` draws its own pixels (`Compositor::draws_own`, true by default) now draws every frame whole: a partial frame copied the kept frame, which holds only Rune's instances, over the compositor's pixels.
