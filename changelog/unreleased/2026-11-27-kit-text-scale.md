- **Text size scales type, not the window.** `rune_kit::TextScale` is a text size an app keeps in its state. `cx.with_text_scale(&s.text_scale, |cx| ..)` (trait `KitCx`) puts it in scope, and every kit `cx.kit()` returns there, from whichever `KitTheme`, has its type at that scale (`Kit::with_text_scale`): each `Type` style, the heights of controls that hold a line of text (buttons, fields, segmented controls, popup and disclosure rows, keybinds), glyphs next to text (button and select icons, icon buttons), the text area's style and the default sidebar, table, tree and tab strip row heights. Padding, radii, gaps and the rest of the layout stay, unlike `Cx::zoom`, and nothing depends on how much room the window has. `Kit` gains a `text_scale` field (1 as a theme builds it); a theme that builds a `Kit` literal adds `text_scale: 1.0`. `k.text(style)` and `k.text_size(points)` scale an app's own styles, icon sizes and row heights to match. `TextScale::menu_items(|s: &mut S| &mut s.text_scale)` gives the View menu's Make Text Bigger (Cmd+=), Make Text Smaller (Cmd+-) and Make Text Normal Size (Cmd+0), stepping through 75 to 250 percent. Add them with `App::menu_item`; `TextStep::from_key` reads the same keys where there is no native menu bar. An app that zoomed the window for text size drops `cx.zoom(..)` for `with_text_scale` around its view. The kit gallery takes the commands.
