- `Tray::set_accessibility_label` replaces the name screen readers announce for a tray icon, which started as the `TraySpec::new` title and could not change: on macOS the status item image's accessibility description (kept across `Tray::set_icon`), on Linux the StatusNotifierItem `Title`; on Windows the icon's tooltip text, which Narrator reads, while the app sets no tooltip of its own (an app tooltip is shown and read instead). A Windows tray with no tooltip now shows its `TraySpec::new` title rather than nothing. `examples/background` takes `tray label <text>` on stdin.
