- macOS: the share picker (`Tx::share`) now opens after the event handler that asked for it returns, as pop-up menus do, so every window keeps drawing while it is on screen. Sharing from several windows keeps each picker's answer, instead of a later share dropping an earlier one's. A share whose window closes, hides or quits before its picker answers (including one asked for in the same handler as `Tx::close_window`) now answers `Ok(None)` while the window's state is alive, as file dialogs do, instead of never answering.
