- **iOS: a bundle carries a privacy manifest.** `scripts/ios-app` copies Rune's `PrivacyInfo.xcprivacy` into every bundle it stages, or the app's own with the new `--privacy FILE`, which is refused when it is not a property list with the four top-level keys. Rune's declares no tracking, no collected data and the two required-reason APIs a Rune app links: file timestamp (`stat` and `fstat`, from reading the app's own files and loading system fonts) and system boot time (`mach_absolute_time`, from wgpu-hal's Metal presentation timestamp). The `RuneView` Swift package ships the same file as a resource, and `scripts/ios-lib` writes a copy to `<out>/PrivacyInfo.xcprivacy` for a host app that doesn't use the package. An app that uses a listed API or collects data itself starts from Rune's file and adds its own entries.
