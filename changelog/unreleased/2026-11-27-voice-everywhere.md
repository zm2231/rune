- `rune::Voice` runs on Linux: a PulseAudio (and so PipeWire) record and playback stream on the default devices, falling back to ALSA, both loaded at run time. Echo cancellation and noise suppression run in the app with WebRTC's AEC3 and noise suppressor through `sonora` 0.3.0 (pure Rust, BSD-3-Clause), using the samples Rune plays as the reference, so no system echo-cancel module is needed; only Rune's own output is cancelled and the microphone level isn't adjusted. A stream that dies is rebuilt and reported as `VoiceEvent::DeviceChanged`. `scripts/voice-pulse-e2e.sh` measures echo against a real PulseAudio server in Docker whose microphone hears the speaker directly. On Windows it runs on WASAPI's default communications devices tagged as communications audio: when the microphone's driver offers the system echo canceller (listed through `IAudioEffectsManager` on Windows 11, and turned on when it can be) the system cancels echo, otherwise the same in-app canceller runs, never both; the speaker is named as the canceller's reference on Windows 11, a change of default communications device rebuilds the stream, and `Voice::permission` reads the microphone privacy setting. Windows hasn't been run on real audio hardware yet.
