- **A frame only a loop asked for runs the loop alone on macOS, Linux and iOS too, a turning icon counts as such a loop, and a rotation can step at its own rate.** Windows already stepped a spinner's dots and a shimmer's window into the instances they drew, with no `poll`, view, layout, paint or instance diff; macOS and Linux windows and iOS views ran every such frame in full, so a few spinners or loaders on an otherwise still screen kept the CPU busy. They now take the same step and draw the whole frame from the stepped instances (only Windows redraws and presents just the changed pixels). On iOS, any touch, key, gesture, wake or system change since the last frame still makes the next one ordinary. An icon turning on `LoopSpec::rotation` (`rune_kit::Loader`'s arc) steps too: its one glyph takes the loop's turn and nothing else moves; a turn of exactly zero, an icon in a layer, scaled, gliding or animated, or a colour icon still takes an ordinary frame. `LoopSpec::fps` steps a rotation that many times a second on a timer instead of every display frame, as `Cycle::fps` does for a cycle; like a stepped cycle it turns on the wall clock, so it keeps its speed on a resting window and each timer wake steps it rather than running an ordinary frame (and the app's `poll`). `rune_kit::Loader` now turns at 60 steps a second. `LoopKind::Rotation` carries the rate (`Rotation { fps }`): a match on it needs `Rotation { .. }`. A spinner scrolled out of sight no longer keeps the ones in sight from stepping, and a spinner inside a faded row steps too, including a row whose fade folds into the spinner's one dot. A loop frame that comes late (up to the quarter second an ordinary frame charges to running motion) still steps, and one that comes before any loop is due redraws what is drawn instead of running the app. On macOS a frame that only stepped loops no longer starts or keeps alive the display link: a 60 fps spinner on a 120 Hz display woke the display link's thread on every refresh between its steps. `RUNE_LOOP_CHECK=1` checks turned icons against ordinary frames as it checks the dots. Debug builds on macOS print each change AppKit reports in a window's occlusion.
