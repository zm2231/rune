- Overlays follow the app's color scheme. `AppHandle::set_color_scheme` now reaches every overlay on macOS, Windows and Linux: `Cx::system_dark` reports the app's `Light` or `Dark` over the system's, and on macOS the overlay panel's `NSAppearance` matches, so an app that forces dark on a light system draws its overlays dark. `Tx::set_color_scheme` in an overlay's handler sets that overlay's own scheme, which wins over the app's until it is set back to `ColorScheme::System`. Overlay views that read `Cx::system_dark` can change appearance in apps that set a scheme.
