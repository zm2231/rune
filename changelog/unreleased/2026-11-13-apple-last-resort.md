- **macOS and iOS: a character no font has loads no font.** For a character nothing installed covers (an unassigned code point such as U+0378), CoreText's fallback answers with its last-resort font, `LastResort.otf`, whose glyphs are placeholder boxes naming the character's block. Rune loaded that file as a fallback family. The last-resort font is now skipped, so such a character adds no font and is a missing glyph like any other. Characters a real font covers load the files they did before.
