- **A spinner is one element.** `El::cycle_dots` (`LoopKind::Dots`, `CycleDot`) draws a set of dots in an element's fill colour, each fading on its own wall-clock `Cycle`, as one element with one loop. `rune_kit::Spinner` is now one such element instead of a parent holding 25 dot elements, with the same look, shared phase and reduced-motion pose. Its dots step without a paint as before, and paint keep now copies the rows around a spinner whole, re-sampling its dots at the paint's clock, where a looping dot kept every row it sat in from being copied. Code that looked up a spinner's dots by key (`d0` to `d24`) finds one element now.
