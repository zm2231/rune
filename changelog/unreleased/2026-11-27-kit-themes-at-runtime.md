- **Kits swap at runtime without leaking, and a sidebar can take its own.** `rune_theme_opencode::kit(dark) -> &'static Kit` is gone. Kits were cached for the life of the process, so an app that derived kits at runtime (an accent, glass panes, a contrast lift) had to leak each one to fit `&'static`. Now `rune_kit::KitTheme` turns each window's `KitEnv` (appearance, blend mode, increased contrast, system accent) into a `Kit`. It keeps the kits of its four latest environments and frees them all when its last clone drops. `cx.with_kit(&theme, |cx| ..)` (trait `rune_kit::KitCx`) scopes a theme over part of the view, and `cx.kit() -> Rc<Kit>` reads the innermost one; outside any theme it returns Rune's neutral kit. Memos built under a theme, and the virtual rows of a view that scopes one, build again when it is replaced. Underneath is a general `Cx::provide(&Provided<T>, |cx| ..)` / `Cx::provided::<T>()`, and increased contrast now joins every memo's environment. Migrating an app:
  - Make each theme once and keep it in app state: `rune_theme_opencode::kit_theme()`, or a derived one, `KitTheme::new(move |env| { let mut k = rune_theme_opencode::kit(env); k.c.bg_accent = accent; k })` (`kit(&KitEnv) -> Kit` is the starting point, with increased contrast applied when the environment asks for it). When the app's look changes, replace the theme; drop any `Box::leak` kit caches. A fixed kit is `KitTheme::fixed(kit)`.
  - At the top of each window's view: `cx.with_kit(&s.theme, |cx| { .. })`. For a region with its own kit (a sidebar or toolbar over glass), wrap its build in another `cx.with_kit(&s.chrome, |cx| ..)`.
  - Where a view called `theme::kit()`: `let k = cx.kit();` once, then pass `&k` where it passed the `&'static Kit` (`Button::new(..).build(&k)`; `k.c.text_base` reads as before).
  - Helpers with no `Cx` (`fn strong() -> Color`) take `k: &Kit` instead of reading a global.
  - Closures that outlive the view (`virtual_rows` rows, handlers that read colours) capture `k.clone()` (an `Rc<Kit>`) or the colours they need, not a borrow.
  - Kits for one appearance outside a window (tests, pictures): `rune_theme_opencode::kit(&KitEnv::new(dark))` or `theme.kit(&KitEnv::new(dark))`; `KitEnv::of(cx).dark(d)` overrides the appearance of the window's environment.
