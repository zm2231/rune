- When a commit reuses a `memo` subtree, its text keeps the layout from the last commit as long as its width and fonts haven't changed, so one changed row among a hundred lays out only that row's text. With `frame-profile`, each `RUNE_FRAME_LOG` line counts the frame's memo hits, misses and new memos (`"memo": {"hit", "miss", "new"}`). `memo`'s docs now say the id must be the item's stable identity, not its position: an index-keyed row is renamed when a row is inserted above it, so every memo below misses.
