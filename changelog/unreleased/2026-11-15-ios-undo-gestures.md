- **iOS: a shake and the three-finger undo gestures undo and redo the focused text field.** While a field has the focus the keyboard's text input answers UIKit's `undoManager` with a manager that holds one undo action and one redo action, kept in step with the field after each frame so that it can do what the field can (the new `TextEdit::can_undo` and `can_redo`); running one sends the field ⌘Z or ⇧⌘Z, so the field's history stays the only one. The manager is asked what it offers only on the frame after it was filled or ran an action, so a frame that changes nothing sends it no message, and it is emptied when the text input goes away. With no field focused there is no manager and nothing is offered. On an iPad the menu bar's Edit › Undo and Redo, UIKit's own items, are enabled the same way. On the iOS simulator a shake's Undo and Redo, the iPad menu bar's and a hardware keyboard's ⌘Z each took one step; the three-finger gestures and a real shake are not yet verified on a device.
