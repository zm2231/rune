- **Services menu.** `App::on_service` (and `WindowSpec::on_service`) receives what the user sends to the app from another app's macOS Services menu: a `ServiceInput` with the selected text, links and files, named by the entry's `NSUserData` so one app can offer several entries. Each `NSServices` entry names the message `runeService` (`rune::SERVICE_MESSAGE`); a service that launches the app arrives before the first frame, and a services provider the app set itself is left alone. `scripts/mac-app --plist PATH` merges extra keys into a development bundle's `Info.plist`. `examples/mac-parity` offers "Send Text to Mac Parity" and "Send Files to Mac Parity".
