- **iOS: one deployment target, 16.0.** `scripts/ios-app` reads what the binary was built for (`xcrun vtool -show-build`) and refuses to bundle one whose minimum iOS is not the bundle's `MinimumOSVersion`, which the new `--min-os X.Y` sets (16.0 unless told, and no lower). A simulator build made without `IPHONEOS_DEPLOYMENT_TARGET` is linked for iOS 14, so it is now refused: set `IPHONEOS_DEPLOYMENT_TARGET = "16.0"` under `[env]` in the app's `.cargo/config.toml`, as Rune's own now does, which also lets a debug device build link. `scripts/ios-lib` builds with 16.0 unless the caller set the variable, and refuses a value below it.
