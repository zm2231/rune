- `Runtime::state` is now `Box<S>`, so the windows of a `SharedState` hand the state over without copying it: a window's turn now costs the same and allocates nothing whatever the size of `S`, where it used to copy the whole state in and out. `Runtime::new` and the app builders still take a plain `S`. Field access (`rt.state.count`), `&rt.state` and `&mut rt.state` work as before; code that uses the state by value adds a `*`: `assert_eq!(rt.state, 3)` becomes `assert_eq!(*rt.state, 3)`, and `rt.state = next` becomes `*rt.state = next`.
