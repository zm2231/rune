- macOS: a timer's frame that draws on a resting window draws at once without starting the display link, and leaves a coasting link's countdown alone, so an app whose timers redraw a few times a second no longer keeps the link (and its Core Video thread) running for 150 ms after each one. The link starts when the frame leaves more frames to draw. With `frame-profile`, `RUNE_FRAME_LOG` also gets a `{"t", "link", "at"}` line each time the link starts, resumes, coasts or stops, naming the code that asked.
