- **iOS: a memory warning frees the caches Rune can make again.** On `UIApplicationDidReceiveMemoryWarningNotification` a `RuneView` gives back what a window at rest gives back: the text layouts the last two commits didn't use and their glyph runs, the images no element showed in the last frame and the CPU copies of the pages left empty, the elements a rewind recording no longer refers to, the `El::cache` textures no layer drew last frame, every spare layer target, and the backdrop copies and blur pyramid when the last frame read no backdrop. On top of that it frees what a rest keeps for a view shown again: the layouts of the commit before the last that no element holds (a view just left), the glyph runs and colour glyphs the last frame laid no quads from, the glyph atlas pages the frame drew nothing from (such a page starts over, the first page too, and the pages after the last one in use go; of the first page only its pixel buffer and texture stay), and the textures of the glyph and image pages that went. All of it goes in the notification itself: nothing waits for a frame, so an app in the background, which draws none, frees it too, and so does a view out of its window (a screen under a pushed one). What is on screen stays, so Rune's own trim draws no frame and doesn't re-run the view; what went is made again when it next shows, at a first frame's cost. An `Image` keeps its pixels while a handle or an element holds it, and a compositor's own textures are untouched. `App::on_rest` runs in it, where a rest runs it: after the caches a rest takes from the runtime, before what the renderer gives back and what the trim frees on top, in the background too, and nothing is submitted to the GPU. A hook that changes what the view shows, or asks its `Tx` for work a frame does, gets a frame at once when the view is in front, and at the first frame back otherwise. New `Runtime::trim_memory`, `Renderer::trim_memory` and `LayerHost::trim_memory` (which does both) do the same, without the hook, for a host that embeds Rune itself. Windows on macOS, Windows and Linux don't call them: they give back at rest.
