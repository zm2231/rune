- **Syntax colours read at 4.5:1, and Increase Contrast strengthens code and diffs.** `rune_kit::syntax::SyntaxTheme::from_kit` holds every token colour to 4.5:1 on the surfaces code sits on (`bg_base`, `bg_deep`, `layer_01`), moving a short one toward black or white along its own hue: in light themes `Variable` (3.0–3.3:1 before) and the neutral theme's `Type`, `Regex` and translucent `Comment` (3.95:1) draw darker, and every token is now opaque. A kit made with `Kit::increased_contrast` sets the new `Kit::increased_contrast` field, which raises that floor to 7:1 for syntax tokens and for code on a `DiffView`'s, a `Note` fence's and a Markdown `diff` fence's change tints, and draws those added and removed tints about 1.6 times as far toward green and red (keeping their lightness where a deeper tint would leave the text short of 7:1, as on dark themes). **Breaking for hand-built kits:** `Kit` has a new public field, so a `Kit { .. }` struct literal no longer compiles until it adds `increased_contrast: false` (kits from `Kit::neutral`, `Kit::from_palette` or `rune_theme_opencode::kit` need no change). `Syntax::ALL` lists every token kind.
