- iOS accessibility: a `RuneView`'s first `accessibilityElements` answer holds the elements of the frame already on screen, built when the client asks, instead of an empty list that only filled in on the next frame. VoiceOver, Voice Control and UI automation (`axe describe-ui`, XCUITest) now see the whole screen on their first query after launch. A query that arrives before the first frame still gets an empty list, and that frame posts `UIAccessibilityScreenChangedNotification` so clients ask again. Apps that never meet an assistive client still build no tree.
