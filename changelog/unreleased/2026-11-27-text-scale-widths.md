- **Menus, selects and other popups fit their text at every text size.** A menu or select listbox is as wide as its widest label, up to the window, rather than cutting labels at its least width; this changes popups with long labels at 1x too. Widths the kit picks for surfaces that hold text follow the kit's text size: menu and submenu least widths, the select listbox's range and trigger width, combobox and popup list widths, hover card and popover ranges (`PopoverMetrics` scales with the other text metrics), the dialog's width and standard height, the standard tooltip's wrap width, the toast's width and action indent, and the image preview's zoom level. Widths an app passes (`Menu::min_width`, `Select::width`, `Select::menu_width`, `HoverCard::width` and the rest) are used as given; popup menus keep the anchor's measured width as a floor. `Menu::standard()` no longer replaces a `min_width` set before it; with none set, a standard menu's least width is 128 points at the default text size. Markdown lists keep a space between each marker and its text: the marker column (32 points by default) follows the text size and widens for a list's widest number. The kit gallery adds stories for tab and sidebar status marks, two-line sidebar rows and avatars.
