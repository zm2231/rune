- **macOS and iOS: Chinese never falls back to PingFang under another name, and has a second choice.** CoreText's fallback for Chinese is PingFang, whose glyphs are in an `hvgl` table Rune has no reader for, so Rune asked for Hiragino Sans GB (Heiti TC for Traditional) by name instead and took whatever came. A system without Hiragino Sans GB loaded nothing for Simplified Chinese, and one that answers a request for Heiti with PingFang loaded PingFang itself; iOS is both. Now the candidates are tried in order (Hiragino Sans GB, Heiti SC, Heiti TC; Heiti TC first for a Traditional locale or PingFang variant), and one counts only when the fonts CoreText resolves it to are not PingFang by their own family or file. When none does, the character goes to the first font of CoreText's cascade list that has it, names a file and isn't PingFang; an entry of the list that is a role with no file (`.AppleJapaneseFont`) is resolved to the font behind it first. A character no such font has gets no font, which is the case for one only Chinese uses where PingFang is the only Chinese font: an app with Chinese text bundles a font for it there. The family chosen and each locale's cascade (8 locales of at most 64 fonts) are kept, so only the first Chinese character asks CoreText for them. macOS loads the files it did before: `Hiragino Sans GB.ttc`, and `STHeiti Light.ttc` and `STHeiti Medium.ttc` for Traditional.
