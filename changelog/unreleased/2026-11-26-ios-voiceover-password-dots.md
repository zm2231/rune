- **iOS: VoiceOver reads a typed password as its dots.** A password field with text gives VoiceOver one dot for each character, as a `UITextField` with `secureTextEntry` does, or a fixed run of dots over several lines. It does so even while the password is revealed on screen. An empty field still reads its placeholder. Only the iOS mirror receives the dots, and the accessibility tree still carries neither a password's text nor its length. `Runtime::ios_accessibility_json` reports them the same way.
