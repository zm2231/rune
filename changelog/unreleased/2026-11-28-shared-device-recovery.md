- **Windows sharing a lost GPU device recover on a software adapter instead of giving up.** D3D12 keeps one device per adapter in a process, so while a second window still held the lost device, the first window's new software (WARP) device came back as the lost one and Rune reported "no software adapter is available" and gave the window up at once. A replacement that fails while another window still holds the old device now tries again after the usual backoff, within the same retry limit.
