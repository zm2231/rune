- `Tray::set_accessibility_label` replaces the name screen readers announce for a tray icon, which started as the `TraySpec::new` title and could not change: on macOS the status item image's accessibility description (kept across `Tray::set_icon`), on Linux the StatusNotifierItem `Title`; a no-op on Windows, where Narrator reads the tooltip. `examples/background` takes `tray label <text>` on stdin.
