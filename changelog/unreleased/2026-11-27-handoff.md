- **Handoff.** `Tx::advertise(Activity::new("com.example.app.viewing").with_title(..).with_info(key, value))` advertises what a window is doing, and `Tx::stop_advertising` stops it. macOS sets it as the window's `userActivity`, re-adding its info whenever AppKit asks the window to update the activity; iOS gives each window its own current activity, apart from the scene's. `App::on_continue_activity` (and `WindowSpec::on_continue_activity`) receives an activity continued from another device, before the first frame when it launched the app; a continued web page goes to `on_open_url`. Activity types are listed in the bundle's `NSUserActivityTypes`. `examples/mac-parity` advertises the selected file and selects it when continued; its `install.sh` now registers the bundle with Launch Services and rescans Services, so Services entries show before the app's first launch.
