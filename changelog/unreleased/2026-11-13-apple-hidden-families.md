- **macOS and iOS: a hidden system font is loaded from its file, never asked for by name.** CoreText names the font it falls back to for a character the app's fonts lack; for Arabic, Hebrew, Indic scripts, Thai and others that font's family is hidden (`.SF Arabic`, `.SF Hebrew`), and Rune went on to ask CoreText for the rest of the family by that name. A hidden name isn't a name to ask for: CoreText's own note on such a request is that the client gets another font than the one it meant, and should reach system fonts through CoreText's calls for them. A fallback whose family is still hidden once its file's public faces are looked at now adds the file CoreText said it is in and nothing else, and no hidden name other than the system font's own (`.SF NS`, `.SF UI` and the families named after them) resolves to files at all. macOS loads the files it did before.
